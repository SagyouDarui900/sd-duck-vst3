# UIデザイン仕様書（REAPER Native & Anti-AI Slop 設計指針）

## 1. デザインフィロソフィー

### 1.1 基本コンセプト：「Cockos純正プラグインの現代的アップデート」
`SD-Duck` のUIは、**「初期状態のREAPER（Default 7.0 テーマおよび ReaComp / JSFX 群）のFXチェーン画面に並べたとき、最初から標準同梱されていたかのように自然に馴染むこと」**を最優先のゴールとする。

昨今のAI生成UIや過剰に装飾された商業プラグインに見られる「見た目の派手さのための重いグラフィック」を排除し、音響制作ツールとしての**視認性・操作密度・描画の軽さ**に全リソースを集中させる。

### 1.2 明確な禁止事項（Anti-AI Slop ルール）
AIによるUI実装時に陥りがちな以下の要素は、本プロジェクトでは**すべて禁止**とする。

- **視差効果（パララックス）や不要なアニメーションの禁止**: UIパーツのスライドイン、バウンス、ホバー時の拡大縮小アニメーションは行わない。操作に対しては1フレームで即座に状態を反映する。
- **過剰なグラデーション・グラスモーフィズムの禁止**: 背景のすりガラス効果（Blur）、金属光沢の疑似グラデーション、立体的なドロップシャドウ（`DropShadow`）、ネオン管のような発光（Glow）エフェクトを使用しない。
- **過度な角丸（`border-radius`）の禁止**: ボタン、パネル、スライダーの角丸は原則 `0px`（完全な直角）とする。
- **装飾アイコン・絵文字の禁止**: 歯車やスピーカー等のベクターイラストや絵文字は使わず、`1px` の幾何学ラインと簡潔な英語テキストラベルのみで機能を示す。

## 2. カラーパレット（REAPER Default Theme 準拠）

REAPERのデフォルトテーマが持つ「目に優しいマットなチャコールグレー」と「落ち着いたティールグリーン（青緑）」を基調とし、波形ビジュアライザの削減量表示のみ彩度を上げて視線を集める設計とする。

### 2.1 ベース＆サーフェスカラー
| 用途 | カラー名 | HEXコード | 備考 |
| :--- | :--- | :--- | :--- |
| **ウィンドウ全体背景** | `Bg_Main` | `#2B2B2B` | REAPERのFXウィンドウ・ミキサー背景と同等のトーン |
| **操作パネル背景** | `Bg_Panel` | `#333333` | コントロール領域のベース色 |
| **ビジュアライザ背景** | `Bg_Canvas` | `#1E1E1E` | 波形とGRカラーのコントラストを確保する暗色 |
| **コントロール入力枠背景** | `Bg_Control` | `#222222` | スライダーバーやドロップダウンの溝の色 |
| **ホバー時背景** | `Bg_Hover` | `#3D3D3D` | マウスオーバー時の控えめな明度変化 |

### 2.2 ボーダー・グリッド線（すべて `1px` ソリッド）
| 用途 | カラー名 | HEXコード | 備考 |
| :--- | :--- | :--- | :--- |
| **外枠・セクション区切り線** | `Border_Dark` | `#181818` | パネル同士を明確に仕切る暗線 |
| **コントロール枠線** | `Border_Light` | `#4A4A4A` | ボタンや入力枠の輪郭（REAPERの標準境界線に近い色） |
| **フォーカス・選択枠線** | `Border_Focus` | `#3BA596` | ドラッグ操作中・アクティブ時の強調枠 |
| **ビジュアライザ補助グリッド** | `Grid_Line` | `#2A2A2A` | 拍（Beat）・dB目盛りの背景グリッド線 |

### 2.3 テキストカラー
| 用途 | カラー名 | HEXコード | 備考 |
| :--- | :--- | :--- | :--- |
| **主要テキスト・数値** | `Text_Primary` | `#E0E0E0` | 純白（`#FFFFFF`）を避け、長時間作業での眼精疲労を防ぐ |
| **パラメータラベル** | `Text_Secondary` | `#9E9E9E` | 項目名や単位（`ms`, `dB`, `Hz`）の表示用 |
| **無効（Disabled）状態** | `Text_Disabled` | `#5A5A5A` | 現在選択中のモードに関係ないパラメータの表示色 |

### 2.4 機能・ビジュアライザカラー（削られた量の色分け）
| 用途 | カラー名 | HEXコード | 視覚的意味 |
| :--- | :--- | :--- | :--- |
| **REAPERシステムアクセント** | `Accent_Teal` | `#2D9384` | アクティブなモードボタン、SC信号正常点灯、標準メーター色 |
| **残存波形（Post-Duck）** | `Wave_Post` | `#C8D6D5` | ダッキング後に実際に残った音声波形（明るいクールグレー） |
| **削られた量：浅い（0〜-6dB）** | `GR_Low` | `#38A89D` | 軽微な音量抑制（シアン〜ティール系） |
| **削られた量：中程度（-6〜-15dB）** | `GR_Mid` | `#D99B26` | 標準的なダッキング（落ち着いたアンバー・イエロー系） |
| **削られた量：深い（-15dB〜）** | `GR_High` | `#D9483B` | 強いダッキング・完全カット（マットなクリムゾンレッド系） |
| **SC未接続警告** | `Status_Warn` | `#C94A38` | `Audio` モード時に `ch 3/4` の信号がない場合の警告表示 |

> **塗りつぶし処理のルール**: 削られた面積（Pre波形とPost波形の差分領域）を塗りつぶす際は、上記 `GR_Low` 〜 `GR_High` を現在の減衰量（dB）に応じて線形補間し、アルファ値（不透明度）`0.35`（約35%）の単色フラット塗りで描画する。上辺のGRカーブ折れ線自体はアルファ値 `1.0`（不透明・線幅 `1.5px`）で描画する。

## 3. タイポグラフィと数値フォーマット

外部フォントファイルは一切同梱せず、Windows 11 環境に標準搭載されているフォントのみを使用する。

- **UIラベル用フォント**: `Segoe UI`（Regular / SemiBold、サイズ `11px 〜 12px`）
- **数値・ステータス用フォント**: `Consolas`（等幅フォント、サイズ `11px 〜 12px`）
  - **等幅フォント必須の理由**: リアルタイムのゲインリダクション値（例: `-14.2 dB`）やパラメータドラッグ中の数値変化において、桁の横揺れ（ジッター）を完全に防止するため。
- **表記フォーマット統一ルール**:
  - デシベル表記は常に符号と小数第1位まで固定表示する（例: `-6.0 dB`, `-18.5 dB`, `0.0 dB`）。
  - ミリ秒表記は `100ms` 未満は小数第1位（`2.5 ms`）、`100ms` 以上は整数（`150 ms`）で統一する。

## 4. レイアウト構造（高密度グリッド設計）

デフォルトウィンドウサイズ `680 x 380 px` における画面構成は以下の3層構造とする。すべての要素は `1px` の境界線で隙間なくタイル状に配置する。

```text
+-----------------------------------------------------------------------+
| [SYNC] [AUDIO] [MIDI]  |  RATE: [1/4 v]  |  SC: ACTIVE (-12.4dB) [ON] | <- Top Bar (28px)
+-----------------------------------------------------------------------+
| 0dB ----------------------------------------------------------------- |
|      \                                         /                      |
| -12dB \   [削られた差分エリア: 減衰量に応じた色] /                      |
|        \_____________________________________/                        |
| -24dB    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^  [残った波形: Post]       | <- Visualizer (242px / ~64%)
|                                                                       |
| [View: 1 Beat v]                                     Max GR: -14.8 dB |
+-----------------------------------------------------------------------+
| [ Depth: 80.0 % ] | [ Attack:  2.0 ms ] | [Split: OFF / 120Hz] | [Mix] |
| [ Thresh: -18.0 ] | [ Hold:   20.0 ms ] | [ Target: Stereo   ] | 100 % | <- Control Panel (110px / ~29%)
| [ SC HPF:  20Hz ] | [ Release: 150 ms ] | [ Curve:    0.00   ] | [SC MON]|
+-----------------------------------------------------------------------+
```

### 各エリアの役割
1. **トップバー（高さ `28px` 固定）**:
   - 左側: トリガーモード切替タブ（`SYNC` / `AUDIO` / `MIDI`）。REAPERのトラックボタン風の矩形トグル。
   - 中央: 選択中モードに応じた主要設定（`SYNC` 時は `Rate: [1/4]`、`AUDIO` 時は `Detect: [1-Shot / Follow]`、`MIDI` 時は `Note: [Any] / Vel: [0%]`）。
   - 右側: サイドチェイン入力ステータス（`ch 3/4` の信号有無とリアルタイムピーク値）。
2. **メインビジュアライザ（高さ可変・全体の約64%）**:
   - 背景に `0dB`, `-6dB`, `-12dB`, `-24dB` の水平グリッド線と、拍（Beat）区切りの垂直グリッド線を `1px` で描画。
   - 左下隅にタイムベース切替（`1 Beat` / `2 Beats` / `1 Bar` / `500 ms` / `1000 ms`）、右下隅に現在の最大ゲインリダクション数値をオーバーレイ表示（背景ボックスは `Bg_Canvas` の不透明度80%・角丸なし）。
3. **コントロールパネル（高さ `110px` 固定）**:
   - 3行 × 4列の均等グリッドセルで構成する。
   - 場所を取るロータリーノブ（円形ツマミ）は一切配置せず、**すべての連続値パラメータを「水平バーゲージ内蔵の数値ボックス」に統一**する。
   - **Splitセルの複合操作**: `Low Split` セルは左端にON/OFFトグル領域（`split_enabled`）、右側に周波数ドラッグ領域（`split_freq`: `30Hz〜500Hz`）を配置し、1セル内で明快にON/OFFと周波数を操作できるようにする。

## 5. カスタムUIコンポーネント仕様（JUCE `LookAndFeel` 指針）

REAPERの「JSFX」や「ReaControlMIDI」のスライダー、あるいはパラメータバーの操作感に近づけるため、以下のカスタムコンポーネントを実装する。

### 5.1 水平バーゲージスライダー（Horizontal Bar Slider）
各グリッドセル（幅約 `170px` × 高さ `36px`）そのものがスライダーとして機能する高密度コントロール。

- **見た目**:
  - セル全体の背景は `Bg_Control`（`#222222`）、枠線は `Border_Dark`（`#181818`）。
  - 左端から現在の値（0%〜100%）の位置まで、落ち着いたティール色（`#265E56`）の矩形バーをフラットに塗りつぶす。
  - テキストは左寄せでパラメータ名（`Text_Secondary`）、右寄せで現在値（`Text_Primary` / `Consolas`）を1行に並べて描画する。
- **操作仕様（REAPER準拠の快適操作）**:
  - **上下または左右ドラッグ**: 値を連続変更（デフォルトは上下ドラッグで精密変更、左右ドラッグも可）。
  - **`Shift` + ドラッグ**: 1/10のステップ幅で微調整（Fine Tune）。
  - **`Ctrl` + クリック または ダブルクリック**: パラメータをデフォルト値に即座にリセット。
  - **右クリック**: テキストボックスがインライン展開し、キーボードから数値を直接入力可能（例: `-18.5` と打って `Enter` で確定）。
  - **マウスホイール**: カーソルを乗せてホイールを回すだけで値を増減。

### 5.2 無効パラメータの視覚的フィードバック
現在のモードで機能しないパラメータ（例: `SYNC` モード選択時の `Threshold` や `SC HPF`）は、非表示にしてレイアウトを崩すのではなく、**位置を固定したままグレーアウト（`Text_Disabled` かつバー非表示）**にする。これにより、モードを切り替えてもボタン位置が一切変わらず、筋肉記憶で操作できる。

## 6. 描画最適化ルール（CPU/GPU負荷の最小化）

1. **ピクセルスナップ（整数座標描画）の徹底**:
   - すべての枠線・グリッド・矩形パネルの座標は整数値（`int` / `Rectangle<int>`）で指定し、`1px` の線がサブピクセル補間によってぼやける（滲む）現象を防ぐ。アンチエイリアスは波形ラインとGRカーブの斜線描画のみに限定して有効化する。
2. **静的背景のキャッシュ化（`Image` バッファリング）**:
   - ビジュアライザのグリッド線や目盛りテキストはウィンドウリサイズ時にのみオフスクリーン画像へ描画し、毎フレームの `paint()` では背景画像の転送と動的波形パス（`juce::Path`）の描画のみを行う。
3. **アイドル時の完全休止**:
   - DAWが停止中かつオーディオ入力が無音で、ユーザーによるマウス操作も行われていない場合、波形フリーズ完了と同時にタイマー（`60fps`）の `repaint()` 呼び出しを停止し、REAPERのCPUメーターに負荷を一切与えない状態にする。
