# [仮称: SD-Duck] - REAPER向け軽量ビジュアル・ダッキング VST3 仕様書

## 1. プロジェクト概要・開発背景

### 1.1 概要
- **プラグイン名**: 仮称（`SD-Duck` / `SD-Carve` 等から決定）
- **ベンダー名（Manufacturer）**: `SagyouDarui`
- **プラグイン形式**: VST3（64-bit専用）
- **対応環境**: Windows 11（x64） / REAPER v7.x 以降
- **技術スタック**: C++20 / JUCE 8 / CMake（GitHub Actionsによる自動ビルド対応）

### 1.2 解決する課題（YTPMV / 音MAD制作ワークフローの最適化）
REAPER標準の `ReaComp` や既存のフリーサイドチェインVSTには以下の課題があり、本プラグインはこれらを単一かつ超軽量なプラグインで解決する。

1. **視覚的フィードバックの不足**: `ReaComp` は時間軸上で「どのタイミングで・どのくらいの深さ・どのようなカーブで音量が下がっているか」を波形で直感的に把握しづらい。
2. **REAPER特有のBPM変化・シーク時のタイミングズレ**: 既存のLFO系ダッキングVST（SideChainer 2等）は、プロジェクト内のBPMマーカーによるテンポ変化や再生位置の途中変更（シーク）時に位相がズレる問題がある。
3. **ロングテールなKick（Gabbaキック等）への対応**: 音MAD/YTPMVで頻出する減衰の長いキックをそのままサイドチェイン入力にすると、ダッキングが解除されず音量が下がりっぱなしになる。
4. **ルーティング設定の煩雑さと確認のしづらさ**: REAPERの `ch 3/4` へのセンド設定やピンコネクタの接続が正しく機能しているか、プラグイン画面上で即座に判別できない。
5. **帯域別・Mid成分ダッキングの簡略化**: キックとベースの低音被り解消や、ボーカルとオケ（Pad等）のセンター成分の干渉回避を、複雑なマルチバンドコンプやダイナミックEQを組まずに実現したい。

## 2. コア機能仕様

### 2.1 トリガーモード（3方式切り替え）
用途や素材の特性に応じて、以下の3つの動作モードを切り替え可能とする。

| モード名 | 動作概要 | 主な用途・メリット |
| :--- | :--- | :--- |
| **Tempo Sync (LFO)** | 外部ルーティング不要で、DAWのテンポ（拍・小節）に同期して指定カーブ通りにダッキングを行う。 | 4つ打ちキック等、一定リズムのダッキング。センド設定が不要で最速で適用可能。 |
| **Audio Sidechain** | 外部オーディオ入力（`ch 3/4`）の音量レベルを検出し、エンベロープフォロワーでダッキングを行う。 | 不規則なリズムのキック、ボーカルに合わせたオケのダッキング。 |
| **MIDI Trigger** | トラックに入力されたMIDIノートオン信号をトリガーとして、設定したエンベロープカーブを実行する。 | ゴーストMIDIトラックを用いた精密なタイミング制御。 |

#### REAPERのBPM変化・シークズレ防止仕様（Tempo Syncモード）
- 内部タイマーによる自走カウントを禁止し、`juce::AudioPlayHead::PositionInfo` から取得した現在の音楽的タイムライン位置（`ppqPosition`）から位相 $p \in [0, 1)$ を毎サンプル直接算出する。
- これにより、プロジェクト途中のBPM変更マーカー、変拍子、ループ再生、再生位置のランダムシーク時においてもタイミングズレをゼロに抑える。

### 2.2 ガバキック対策：ワンショット・トランジェント検出（Audio Sidechainモード）
- `Audio Sidechain` モード内に **`Detection Type`** 切り替えを搭載する。
  - **Follow (通常)**: 入力音声のエンベロープ（音量変化）に忠実に追従する。ボーカルやスネア等のダッキング向け。
  - **One-Shot (トランジェント)**: 入力信号が `Threshold` を超えた瞬間（立ち上がり）のみをトリガーとして検出し、その後の入力音声の尾引き（サステイン・リリース）を無視して、設定された `Hold` と `Release` の時間通りに元の音量へ復帰する。再トリガーには一定のリトリガー不応期（例: `30ms`）またはヒステリシスを設ける。

### 2.3 ミックス補助機能（周波数帯域制限・MS処理）
複雑なルーティングや追加プラグインなしで実践的なミックス処理を行えるよう、以下の2機能を搭載する。

- **Split-Band Ducking（低域限定ダッキング）**:
  - `Crossover Freq` パラメータ（`OFF` または `30 Hz 〜 500 Hz`）を設定可能にする。
  - 有効時は4次Linkwitz-Rileyフィルタ（24dB/oct、位相補償済み）で入力信号を低域（Low）と高域（High）に分割し、**低域成分のみ**にダッキングを適用して高域と再合成する（ベースやシンセのアタック感を残したままキックの低音域だけを空ける用途）。
- **Target Channel（Stereo / Mid-Only）**:
  - ダッキング対象を `Stereo (L+R)` と `Mid (L+Rの和成分のみ)` から選択可能にする。
  - `Mid` を選択した場合、Side成分（左右の広がり成分）は音量を維持したままセンター定位の成分だけをダッキングする（ボーカル発声時にオケやPadのセンター帯域だけを自然に引っ込める用途）。

### 2.4 視覚化（ビジュアライザ）仕様
ウィンドウ面積の約65%〜70%をメインモニターに割り当て、「どこが・どれだけ削られたか」を色で直感的に判別できるように描画する。

1. **差分カラー可視化（Cutout / Gain Reduction Highlight）**:
   - **残った音（Post-Duck波形）**: ダッキング後に実際に鳴っている音声波形を明るいホワイト〜クールシアンで描画する。
   - **削られた音（Gain Reduction差分エリア）**: 処理前（Pre-Duck）と処理後（Post-Duck）の波形の差分（＝削り取られた音量領域そのもの）を、半透明の**レッド〜オレンジ系の塗りつぶし**でハイライト描画する。これにより「削られた面積」が色付きで一目で視認できる。
2. **減衰深度に応じた動的カラー変化（Depth-Mapped Color）**:
   - ゲインリダクション（GR）カーブのラインおよび差分ハイライトの色は、現在の減衰量（dB）に応じてリアルタイムに色相が変化する。
     - 浅い減衰（`0 dB 〜 -6 dB`）: **シアン / グリーン系**（軽微な音量調整）
     - 中程度の減衰（`-6 dB 〜 -15 dB`）: **イエロー / アンバー系**（標準的なサイドチェイン）
     - 深い減衰（`-15 dB 〜 -∞ dB`）: **オレンジ / レッド系**（強いダッキング・完全カット）
   - 画面上端を `0 dB` とし、実際のゲイン減衰量の推移を折れ線でリアルタイム描画する。
   - タイムベース切り替え: 表示時間幅を `1 Beat` / `2 Beats` / `1 Bar` / `500 ms` / `1000 ms` から選択可能。
3. **インタラクティブ・カーブエディタ（Tempo Sync / MIDI Trigger / One-Shot時）**:
   - 画面上にダッキングのエンベロープカーブ（Attack / Hold / Release / Curve）を表示し、コントロールポイントのドラッグ操作で直感的にカーブ形状を編集できる。
4. **REAPERルーティング診断インジケーター**:
   - `ch 3/4` の入力レベルを常時監視し、画面上部にステータスを表示する。
   - 信号入力あり: `[SC ACTIVE: -12.4 dB]`（緑色点灯）
   - `Audio Sidechain` 選択中かつ `ch 3/4` が無音（-90dB以下）の場合: `[NO SC SIGNAL - Route trigger track to ch 3/4]`（警告表示）を表示し、センド設定忘れやピンコネクタの不備を即座に通知する。

## 3. パラメータ一覧

すべてのパラメータはREAPERのオートメーションおよびパラメータモジュレーションと双方向同期させる。

| パラメータID | 表示名 | 範囲 | デフォルト値 | 単位 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `mode` | Mode | Sync / Audio / MIDI | Sync | - | トリガー方式の切り替え |
| `sync_rate` | Rate | 1/1, 1/2, 1/4, 1/8, 1/16, 1/4T, 1/8D | 1/4 | Note | Tempo Sync時の周期 |
| `sc_detect` | Detect Type | Follow / One-Shot | One-Shot | - | Audioモード時の検出方式 |
| `threshold` | Threshold | -60.0 〜 0.0 | -18.0 | dB | Audioモード時の検出閾値 |
| `depth` | Depth | 0.0 〜 100.0 | 80.0 | % | 最大減衰量（100%で完全無音） |
| `attack` | Attack | 0.0 〜 100.0 | 2.0 | ms | ゲイン減衰にかかる時間 |
| `hold` | Hold | 0.0 〜 500.0 | 20.0 | ms | 最大減衰量を維持する時間 |
| `release` | Release | 10.0 〜 1000.0 | 150.0 | ms | 元の音量に復帰する時間 |
| `curve` | Curve | -1.0 〜 +1.0 | 0.0 | - | リリースカーブの湾曲度（対数〜線形〜指数） |
| `split_freq` | Low Split | 20 〜 500 (20=OFF) | 20 | Hz | 低域限定ダッキングのクロスオーバー周波数 |
| `channel_mode` | Target | Stereo / Mid Only | Stereo | - | ダッキング適用対象成分 |
| `sc_hpf` | SC HPF | 20 〜 2000 | 20 | Hz | サイドチェイン検出用ハイパスフィルタ |
| `sc_lpf` | SC LPF | 200 〜 20000 | 20000 | Hz | サイドチェイン検出用ローパスフィルタ |
| `sc_listen` | SC Listen | Off / On | Off | - | サイドチェイン入力信号のソロモニタリング |
| `mix` | Mix | 0.0 〜 100.0 | 100.0 | % | ドライ/ウェット比率 |

## 4. UI / UX 設計仕様（Windows 11 / REAPER向け軽量・高密度設計）

多トラックに数十個インサートしてもDAWの動作が重くならないよう、以下のUI基準を厳守する。

1. **装飾を排したシャープ＆フラットデザイン**:
   - 角丸（`border-radius`）、ドロップシャドウ、パネル背景の立体グラデーション、発光（Glow）エフェクトを使用しない（波形ビジュアライザの減衰量に応じた色変化のみ軽量なRGB補間で描画する）。
   - セクション区切りはすべて `1px` のソリッドライン（直線）で構成する。
   - 絵文字やアイコンフォントは使用せず、簡潔な英語ラベルと幾何学図形のみでUIを構成する。
2. **高密度レイアウト**:
   - デフォルトウィンドウサイズ: `680 x 380 px`（最小 `500 x 300 px`、アスペクト比自由でリサイズ可能）。
   - 上部70%をビジュアライザ（波形＆カーブエディタ）、下部30%をパラメータ操作パネル（数値ドラッグボックス兼バーゲージ）に割り当てる。
3. **描画パフォーマンスの最適化**:
   - フォントファイルは同梱せず、Windows 11標準のシステムフォント（ラベル用 `Segoe UI`、数値用等幅フォント `Consolas`）を使用する。
   - 描画フレームレートは最大 `60 fps` に制限し、再生停止中かつUI操作がないアイドル時はタイマー描画を自動停止してGPU/CPU使用率を `0%` に抑える。
   - Windows環境ではDirect2Dレンダラーを優先有効化する。

## 5. DSPおよびオーディオ処理要件

- **ゼロレイテンシ動作**:
  - プラグイン遅延補正（PDC）は常に `0 samples` とする。
- **クリッピング・プチノイズ（クリックノイズ）防止**:
  - 急激なゲイン変化（特に `Attack = 0.0ms` や `Tempo Sync` の周期リセット時）による波形不連続を防ぐため、ゲイン係数に対して最小 `1.5ms 〜 2.0ms` の超高速ワンポールスムージングフィルタを適用する。
- **リアルタイムスレッド（Audio Thread）の安全性**:
  - `processBlock()` 内でのヒープメモリ確保（`new`, `malloc`, `std::vector` のリサイズ等）、ロック（`std::mutex`）、システムコールを完全に禁止する。
  - オーディオ処理スレッドからGUIスレッドへの波形データ転送には、固定長ロックフリーリングバッファ（SPSC FIFO）を使用する。
- **REAPERバス構成の明示的定義**:
  - `BusesProperties` にて、メイン入出力（Stereo: `ch 1/2`）とサイドチェイン入力（Stereo: `ch 3/4`、デフォルト有効）を定義し、REAPERの「プラグイン ピン・コネクタ」で自動的に `3/4 -> Side Chain 1/2` として認識されるようにする。
