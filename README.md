# SD-Duck

REAPER向けビジュアル・ダッキング VST3 プラグイン (Windows 64-bit)

## 概要

`SD-Duck` は、入力音声に対して音量抑制（ダッキング）を行う VST3 プラグインです。  
DAWの再生位置への完全同期、外部オーディオ入力（サイドチェイン）、およびMIDIノートオンによるトリガーに対応しています。また、周波数帯域の分割処理やMid成分のみへの適用、削られた音量領域の波形表示機能を備えています。

- **対応形式**: VST3（64-bit）
- **対応OS**: Windows 10 / Windows 11 (x64)
- **テスト済みDAW**: REAPER v7.x 以降
- **フレームワーク**: JUCE 8 (C++20)
- **ライセンス**: GNU General Public License v3.0 (GPLv3)

## 主な機能

### 1. トリガー方式（3モード）

用途に応じて3種類のトリガー方式を選択できます。

| モード名 | 動作 | 主な用途 |
| :--- | :--- | :--- |
| **`Sync` (Tempo Sync)** | DAWの音楽的タイムライン位置（`ppqPosition`）から毎サンプル位相を直接算出します。内部タイマーによる自走を行わないため、プロジェクト途中のBPM変更マーカー、変拍子、ループ再生、ランダムシーク時にも位相ズレが生じません。再生停止時はゲインを自動的に 1.0 へ復帰させます。 | 4つ打ちキックなど、一定リズムでの周期的なダッキング |
| **`Audio` (Sidechain)** | 外部入力（`ch 3/4`）のオーディオ信号を検出し、ダッキングを実行します。 | 不規則なリズムのキック、スネア、ボーカルに合わせたダッキング |
| **`MIDI` (MIDI Trigger)** | プラグインに入力されたMIDIノートオン信号を受信したサンプル位置でエンベロープを実行します。 | ゴーストMIDIトラックを用いた精密なタイミング制御 |

#### Audio モードの検出タイプ
- **Follow**: 入力音声のエンベロープ（音量変化）に連続して追従します。
- **One-Shot**: 入力信号が `Threshold` を超えた瞬間（立ち上がり）のみをトリガーとし、その後のサステインやリリース成分を無視して、設定された `Hold` と `Release` の時間通りに音量を復帰させます。一定のリトリガー不応期（30 ms）およびヒステリシス（-3 dB）を備えており、減衰の長いキック（ガバキック等）でダッキングが解除されなくなる現象を防止します。

#### MIDI モードの制御
- **MIDI Note**: 反応するMIDIノート番号を指定します（`0 = Any Note`、`1〜128 = ノート番号 0〜127`）。
- **Vel Sens**: ノートオンのベロシティに応じた減衰深度のスケーリング比率（0〜100%）を設定します。

---

### 2. ミックス処理

- **Split-Band Ducking（低域限定ダッキング）**:
  4次Linkwitz-Rileyフィルタ（LR4 / 24 dB/oct）により入力信号を低域と高域に分割し、低域成分のみにダッキングを適用して高域成分と再合成します。合成時の振幅応答はフラットに保たれます。ベースの低音域のみをキックに合わせて抑制し、中高域のアタック感を維持する用途に使用します。
- **Target Channel（Stereo / Mid Only）**:
  ダッキングの適用対象を `Stereo (L/R)` または `Mid (センター成分のみ)` から選択できます。`Mid Only` 選択時は $M = 0.5(L + R), S = 0.5(L - R)$ に変換し、$M$ 成分のみをダッキングして再合成します。Side成分（ステレオの広がり）を維持したまま、センター定位の音量のみを抑制できます。
- **Mix（Dry/Wet）**:
  未処理原音（LR4フィルタ適用前）と最終処理済み音声のブレンド比率を調整します。

---

### 3. ビジュアライザ

- **差分カラー表示**:
  処理後の残存波形（Post-Duck）を明るいクールグレー（`#C8D6D5`）で描画し、処理前後の差分（削られた音量領域）を減衰深度に応じたカラー（alpha 0.35）で塗りつぶし表示します。
  - 浅い減衰（0 〜 -6 dB）: シアン系（`#45B8AC`）
  - 中程度の減衰（-6 〜 -15 dB）: アンバー系（`#D99B26`）
  - 深い減衰（-15 dB 以下）: クリムゾンレッド系（`#D9483B`）
- **ゲインリダクション曲線**:
  画面上端を 0 dB、下端を -24 dB とした固定スケールで減衰量の推移を線幅 1.5 px の折れ線で描画します（-24 dB 以下の信号は底部境界でクリップ）。
- **Max GR 数値表示**:
  ピークホールド（約0.75秒間保持）および減衰復帰（Decay）処理を施した最大ゲインリダクション値を等幅フォントで右下に表示します。
- **ルーティング診断**:
  トップバーにサイドチェイン入力（`ch 3/4`）の受信状態（`SC: ACTIVE (-XX.X dB)` または `SC: NO SIGNAL`）を表示します。
- **描画負荷の抑制**:
  再生停止中でかつ入力信号が無音（-90 dB以下）の状態が1秒継続した場合、波形描画タイマーの画面更新を自動休止します。

---

### 4. DSP仕様

- **ゼロレイテンシ**: PDC（プラグイン遅延補正）は 0 samples です。先読み処理による遅延は発生しません。
- **クリックノイズ防止**: 算出されたゲイン係数に対して時定数 $\tau = 1.0\text{ ms}$ のワンポールローパススムージングフィルタを常時適用します。急峻なアタック設定時や周期リセット時の波形不連続によるプチノイズを防止します。

## パラメータ一覧

すべてのパラメータは DAW のオートメーションおよびプロジェクト保存（APVTS）に対応しています。

| パラメータID | 表示名 | 型・範囲 | デフォルト値 | 単位 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `mode` | Mode | Choice: `Sync` / `Audio` / `MIDI` | `Sync` | - | トリガー方式の選択 |
| `sync_rate` | Rate | Choice: `1/1`, `1/2`, `1/4`, `1/8`, `1/16`, `1/4T`, `1/8D` | `1/4` | Note | Syncモード時の周期長 |
| `sc_detect` | Detect Type | Choice: `Follow` / `One-Shot` | `One-Shot` | - | Audioモード時の検出方式 |
| `threshold` | Threshold | Float: -60.0 〜 0.0 | -18.0 | dB | Audioモード時の検出閾値 |
| `depth` | Depth | Float: 0.0 〜 100.0 | 80.0 | % | 最大音量減衰率（100%で無音） |
| `attack` | Attack | Float: 0.0 〜 100.0 | 2.0 | ms | 減衰にかかる時間（中央値 10 ms の対数変化） |
| `hold` | Hold | Float: 0.0 〜 500.0 | 20.0 | ms | 最大減衰量を維持する時間（中央値 50 ms の対数変化） |
| `release` | Release | Float: 10.0 〜 1000.0 | 150.0 | ms | 原音の音量に復帰する時間（中央値 150 ms の対数変化） |
| `curve` | Curve | Float: -1.0 〜 +1.0 | 0.0 | - | リリース曲線の形状（-1.0: 対数 / 0.0: 線形 / +1.0: 指数） |
| `split_enabled` | Split Active | Bool: Off / On | Off | - | 低域限定ダッキングの有効/無効 |
| `split_freq` | Split Freq | Float: 30.0 〜 500.0 | 120.0 | Hz | LR4クロスオーバー周波数 |
| `channel_mode` | Target | Choice: `Stereo` / `Mid Only` | `Stereo` | - | ダッキング処理の適用対象成分 |
| `midi_note` | MIDI Note | Int: 0 〜 128 | 0 | Note | MIDIトリガー対象（0 = 全ノート、1〜128 = ノート 0〜127） |
| `midi_vel_sens` | Vel Sens | Float: 0.0 〜 100.0 | 0.0 | % | MIDIベロシティによるDepth変調感度 |
| `sc_hpf` | SC HPF | Float: 20.0 〜 2000.0 | 20.0 | Hz | サイドチェイン検出信号用ハイパスフィルタ |
| `sc_lpf` | SC LPF | Float: 200.0 〜 20000.0 | 20000.0 | Hz | サイドチェイン検出信号用ローパスフィルタ（HPF+10Hz以上にクランプ） |
| `sc_listen` | SC Listen | Bool: Off / On | Off | - | 有効時、検出用サイドチェイン信号をメイン出力へスルー出力 |
| `mix` | Mix | Float: 0.0 〜 100.0 | 100.0 | % | 原音（Dry）と処理音（Wet）の混合比率 |

## REAPERでのサイドチェイン（Audioモード）設定手順

```text
[トリガー元トラック (例: Kick)]
       │
       └─── センド設定 (ROUTE) ───> Audio: 1/2 => 3/4 ───┐
                                                         ▼
[適用先トラック (例: Bass)]                        [SD-Duck (VST3)]
       │                                           ┌──────────────┐
       └─────── トラック音声 (ch 1/2) ────────────>│ Main In (1/2)│
                                                   │ SC In   (3/4)│
                                                   └──────────────┘
```

1. トリガー元（キック等）のトラックの `ROUTE` ボタンをクリックします。
2. **「新しいセンドを追加... (Add new send...)」** から、適用先（ベースやオケ等）のトラックを選択します。
3. 送信先のオーディオチャンネルを **`Audio: 1/2 => 3/4`** に変更します。
4. 適用先トラックに `SD-Duck` を挿入し、モードを `AUDIO` に設定します。
5. トップバー右側の表示が `SC: ACTIVE (-XX.X dB)` と緑色で点灯していれば設定完了です。
   - 信号が届いていない場合は `SC: NO SIGNAL` と赤色で表示されます。センド設定およびトリガー元の再生状態を確認してください。
   - `[MON]` ボタンを有効にすると、フィルタ適用後のサイドチェイン入力音声を直接モニタリングできます。

## インストール手順

### バイナリからの導入
1. リリースページから `SD-Duck-v*.*.*-win64-vst3.zip` をダウンロードします。
2. 解凍して得られる `SD-Duck.vst3` ディレクトリを以下のフォルダに配置します。
   ```text
   C:\Program Files\Common Files\VST3\
   ```
3. DAWを起動し、プラグインの再スキャン（REAPERの場合: `Preferences -> Plug-ins -> VST -> Rescan`）を実行します。

---

## ビルド手順

### 必要環境
- Windows 10 / Windows 11 (x64)
- CMake 3.22 以降
- Visual Studio 2022（C++デスクトップ開発ワークロード）または Build Tools
- Git

### ビルド実行手順
```powershell
# 1. ソースコードの取得
git clone https://github.com/your-username/sd-duck-vst3.git
cd sd-duck-vst3

# 2. CMakeの構成 (JUCE 8 が自動取得されます)
cmake -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Release

# 3. ビルド
cmake --build build --config Release --target SD-Duck_VST3
```

ビルドが完了すると、`build/SD-Duck_artefacts/Release/VST3/SD-Duck.vst3` に成果物が生成され、`C:\Program Files\Common Files\VST3\` に自動的に上書き配置されます。
